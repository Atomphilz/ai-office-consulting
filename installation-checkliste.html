Name Datum

01Vorher erledigen

  • Claude-Abo auf eigenen Namenclaude.ai, Claude Pro. Zugangsdaten bereitlegen.
  • Administratorrechte am RechnerBei Firmenrechnern vorher mit der IT klären.
  • Scanner oder Handy-ScanDrucker im WLAN, Modell notiert; Handy als Ersatz.
  • Format vom SteuerberaterPortal, Ordner, Dateinamen? Zugangsdaten zum Portal.
  • Zugangsdaten bereitlegenMail, Kalender, Cloud, Banking, Website. Passwörter bleiben bei dir.
  • Zwei eigene TexteEine Mail und eine Nachricht, unverändert. Daraus lernt der Assistent den Ton.

02Die sieben Schritte

SchrittWo und wieFertig, wennOk
1Git installieren5 Min. Bringt unter Windows „Git Bash“ mit. Windowsgit-scm.com/download/win, Voreinstellungen lassenMacxcode-select --install git --version zeigt im Terminal eine Versionsnummer.
2VS Code installieren5 Min. Das Arbeitsfenster. code.visualstudio.com, Installer starten, Voreinstellungen lassen VS Code startet.
3Claude Code installieren5 Min. Danach in VS Code die Erweiterung „Claude Code“ installieren. PowerShellirm https://claude.ai/install.ps1 | iexMac, Terminalcurl -fsSL https://claude.ai/install.sh | bash Ein neues Terminal zeigt auf claude --version eine Versionsnummer.
4Anmelden3 Min. Browser öffnet sich, mit dem Claude-Konto bestätigen. Terminalclaude Claude antwortet auf „Hallo“. Raus mit /exit.
5Das Kit laden5 Min. ZIP entpacken, Ordner umbenennen in aiOS, nach Dokumente. github.com/Atomphilz/aios-kit, grüner Knopf Code, Download ZIP Im Ordner aiOS liegt direkt die Datei CLAUDE.md.
6Ordner öffnen, /onboard20 Min. Sieben Fragen, bei der zweiten die beiden Texte einfügen. VS Code: Datei → Ordner öffnen → aiOS, Autoren vertrauen, Claude-Symbol links, dann /onboard Im Ordner context liegen drei Dateien; die Wochenfrage nennt die eigenen Prioritäten.
7Tagesritual einrichten15 Min. Einmalig, höchstens sieben Fragen. Claude Code/day-setup references/tagesritual.md existiert.
