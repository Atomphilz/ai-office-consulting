Installation: Ihr AI Operating System in sieben Schritten

Vom leeren Rechner zum laufenden Assistenten. Sie tippen, ich sitze daneben. Diese Seite ist der rote Faden für den ersten Tag und das Nachschlagewerk danach.

  • Etwa eine Stunde, inklusive Anmeldung und erstem Gespräch mit dem Assistenten.
  • Windows 10 oder 11, oder ein Mac. Sie brauchen Administratorrechte auf dem Rechner.
  • Alles läuft auf Ihrem Rechner. Ihre Dateien bleiben bei Ihnen.

Die Schritte unten passen sich an. Beim Kunden vor Ort: Windows ist der Normalfall.

Checkliste zum Ausdrucken

01Vorher erledigen

Sechs Dinge, die vor dem Tag bereitliegen. Jedes spart am Tag selbst eine halbe Stunde Warten.

  • Claude-Abo auf Ihren NamenClaude Pro, etwa 20 € im Monat, bei claude.ai. Das Abo ist Ihr Konto, nicht meins; der Assistent läuft darüber.
  • Administratorrechte auf dem RechnerZum Installieren von Programmen. Bei Firmenrechnern vorher mit der IT klären.
  • Scanner oder Handy-ScanPapierbelege müssen digital werden. Scanner am Drucker einrichten, oder eine Scan-App auf dem Handy (zum Beispiel die Notizen-App am iPhone oder Google Drive am Android).
  • Format vom SteuerberaterWie sollen Belege ankommen: Portal, Ordnerstruktur, Dateinamen? Eine kurze Nachfrage reicht.
  • Zugangsdaten bereitlegenE-Mail-Programm, Kalender, Cloud-Ordner, Website. Was angebunden wird, entscheiden wir am Tag; die Passwörter bleiben bei Ihnen.
  • Zwei eigene TexteEine E-Mail und eine Nachricht, die Sie kürzlich geschrieben haben. Unverändert. Der Assistent lernt daraus Ihren Ton.

02Die sieben Schritte

In dieser Reihenfolge. Jeder Schritt endet mit einer Prüfung, an der Sie sehen, dass er geklappt hat.

  1. Git installieren

    5 Minuten

    Git bringt die Kommandozeile „Git Bash“ mit, die Claude Code unter Windows braucht. Installer laden, starten, alle Voreinstellungen so lassen und durchklicken.

    Auf dem Mac ist Git schon dabei, es muss nur einmal freigeschaltet werden. Terminal öffnen (Spotlight: Terminal) und den Befehl ausführen; ein Fenster fragt nach der Installation der Befehlszeilenwerkzeuge.

    Git for Windows laden
    Terminal
    xcode-select --install

    Fertig, wenn „Git Bash“ im Startmenü steht und git --version im Terminal eine Versionsnummer zeigt.

  2. VS Code installieren

    5 Minuten

    VS Code ist das Fenster, in dem Sie mit dem Assistenten arbeiten: links die Dateien, rechts das Gespräch. Installer laden, starten, Voreinstellungen lassen.

    VS Code laden

    Fertig, wenn VS Code startet. Sprache auf Deutsch umstellen ist möglich, aber nicht nötig.

  3. Claude Code installieren

    5 Minuten

    PowerShell öffnen (Startmenü, PowerShell tippen) und den Befehl einfügen. Danach in VS Code die Erweiterung „Claude Code“ installieren: links das Erweiterungen-Symbol, „Claude Code“ suchen, Installieren.

    Terminal öffnen und den Befehl einfügen. Danach in VS Code die Erweiterung „Claude Code“ installieren: links das Erweiterungen-Symbol, „Claude Code“ suchen, Installieren.

    PowerShell
    irm https://claude.ai/install.ps1 | iex
    Terminal
    curl -fsSL https://claude.ai/install.sh | bash
    Erweiterung im MarketplaceOffizielle Installationsanleitung

    Fertig, wenn ein neues Terminalfenster auf claude --version eine Versionsnummer zeigt.

  4. Anmelden

    3 Minuten

    Im Terminal claude eingeben. Beim ersten Start öffnet sich der Browser; dort mit dem Claude-Konto aus der Vorbereitung anmelden und bestätigen. Zurück im Terminal erscheint die Eingabezeile.

    Terminal
    claude

    Fertig, wenn Claude auf „Hallo“ antwortet. Mit /exit wieder raus.

  5. Das Kit laden

    5 Minuten

    Das Kit ist ein Ordner mit Anleitungen und Skills, noch ohne Ihre Daten. Auf der GitHub-Seite den grünen Knopf Code, dann Download ZIP. Die ZIP entpacken und den Ordner umbenennen in aiOS, abgelegt in DokumenteDokumente.

    Kit auf GitHubDirekt als ZIP

    Fertig, wenn im Ordner aiOS direkt die Datei CLAUDE.md liegt, nicht erst in einem Unterordner.

  6. Ordner öffnen und /onboard

    20 Minuten

    In VS Code: Datei → Ordner öffnen, den Ordner aiOS wählen, „Ja, ich vertraue den Autoren“. Dann das Claude-Symbol in der linken Leiste anklicken. Im Gespräch eingeben:

    Claude Code
    /onboard

    Sieben Fragen: wer Sie sind, was Sie anbieten, was dieses Quartal zählt, wo Geld, Mails und Dokumente liegen, was die Woche frisst. Bei der zweiten Frage die beiden vorbereiteten Texte einfügen. Am Ende schreibt der Assistent seine Dateien und schlägt die erste Frage vor: „Worauf soll ich mich diese Woche konzentrieren?“

    Direkt danach, zwei Minuten: vier Fragen dazu, wie vertraut Sie mit Computer und KI sind. Daraus legt der Assistent fest, wie viel er erklärt und welche Wörter er voraussetzt. Keine Prüfung, jederzeit änderbar, und er stellt sich im Alltag von selbst nach.

    Claude Code
    /einstufung

    Fertig, wenn im Ordner context drei Dateien liegen, die Antwort auf die Wochenfrage Ihre Prioritäten nennt, nicht allgemeine, und references/sprache.md existiert.

  7. Das Tagesritual einrichten

    15 Minuten

    Einmalig. Höchstens sieben Fragen: welche Bereiche, was abends erfasst wird, was morgens geprüft wird, welche Werkzeuge. Daraus entsteht die Datei, aus der Abend und Morgen alles Persönliche lesen.

    Claude Code
    /day-setup

    Fertig, wenn references/tagesritual.md existiert. Heute Abend /day-close, morgen früh /day-open. Ab da läuft es.

Der erste Ablauf, den wir danach gemeinsam bauen, ist die Belegablage für den Steuerberater: Belege scannen, der Assistent sortiert und benennt, Sie prüfen. Damit hat der Tag ein greifbares Ergebnis.

03Die neun Skills

Ein Skill ist ein Befehl mit Schrägstrich, der einen festen Ablauf startet. Diese neun sind im Kit.

/onboardTag 1

Sieben Fragen, dann kennt der Assistent Person, Geschäft, Prioritäten und Ton.

/einstufungTag 1

Vier Fragen, dann weiß der Assistent, wie viel er erklärt und welche Wörter er bei Ihnen voraussetzt.

/day-setupEinmal

Richtet das Tagesritual ein: Bereiche, Abendfragen, Morgenquellen.

/day-closeJeden Abend, 5 Min.

Schließt den Tag, fängt lose Zusagen ein, plant morgen.

/day-openJeden Morgen, 1 Min.

Liest den Plan vor und meldet nur, was ihn bricht.

/auditTag 7, dann wöchentlich

Prüft, was der Assistent kennt und erreicht, mit Punktestand.

/level-upWöchentlich

Findet eine Automatisierung, grenzt sie ein, baut sie. Eine pro Woche.

/grill-meBei Bedarf

Vertieft den Kontext, eine Frage nach der anderen.

/linkBei Bedarf

Macht einen neuen Ordner oder eine Quelle für den Assistenten auffindbar.

05Wenn etwas hakt

„claude“ wird nicht gefunden

Das Terminal kennt den neuen Befehl erst nach einem Neustart. Terminalfenster schließen, neu öffnen, noch einmal versuchen. Hilft das nicht: Schritt 3 wiederholen.

Claude Code meldet, Git Bash fehle

Git for Windows ist nicht oder an einen ungewöhnlichen Ort installiert. Schritt 1 mit den Voreinstellungen wiederholen, dann Rechner neu starten.

Der Mac fragt nach „Befehlszeilenwerkzeugen“

Das ist Schritt 1. Installation bestätigen, ein paar Minuten warten, dann weiter.

Die Anmeldung dreht sich im Kreis

Im Browser muss dasselbe Konto angemeldet sein, auf dem das Abo läuft. Anderes Konto abmelden, dann claude erneut starten.

Der Assistent findet die Skills nicht

Meist ist der falsche Ordner geöffnet. In VS Code muss der Ordner offen sein, in dem CLAUDE.md direkt liegt, nicht der Ordner darüber.

Es fragt bei jedem Schritt nach Erlaubnis

Das ist gewollt. Am ersten Tag bleibt es so; was dauerhaft erlaubt sein darf, legen wir am Tag 7 fest.

Die Installation braucht Administratorrechte

Ohne Adminrechte geht es nicht. Auf Firmenrechnern die IT bitten, Git, VS Code und Claude Code freizugeben.

06Und danach

  1. Das Ritual

    Abends /day-close, morgens /day-open. Fünf Minuten plus eine. Ausgelassene Tage werden nicht gezählt, die Kette setzt sich einfach fort.

  2. Erste Prüfung

    /audit zeigt, was der Assistent kennt, was er erreicht und was fehlt. Wir besprechen den Bericht im ersten Termin.

  3. Eine Automatisierung pro Woche

    /level-up. Nichts wird automatisiert, was von Hand noch nicht läuft. Erst Struktur, dann Automatik.
